# 🎵 Jamming: Playlist Creator

Jamming es una aplicación web que permite a los usuarios crear y guardar listas de reproducción personalizadas en su cuenta de Spotify. 🚀

## 🌐 Tecnologías Utilizadas

- **Frontend:** React, JavaScript, HTML, CSS
- **API Externa:** Spotify Web API
- **Gestión de Estado:** useState, useEffect

## 📌 Características Principales

- 🔍 **Búsqueda de Canciones** – Encuentra cualquier canción en la base de datos de Spotify.
- 🎧 **Previsualización de Resultados** – Muestra los resultados en tiempo real.
- 📂 **Creación de Playlist** – Agrega canciones a una lista personalizada.
- 💾 **Guardado en Spotify** – Guarda la lista de reproducción directamente en tu cuenta de Spotify.
- 🎨 **Interfaz Intuitiva** – Diseño moderno.

## 🚀 Instalación y Uso

### 1️⃣ Clonar el Repositorio
```bash
git clone [(https://github.com/AndresGomezV/Jammming)]
cd Jammming
```

### 2️⃣ Configurar el Proyecto
- Asegúrate de tener **Node.js** instalado.
- Instala las dependencias con:
  ```bash
  npm install
  ```
- Ejecuta la aplicación con:
  ```bash
  npm start
  ```

### 3️⃣ Configurar API de Spotify
- Crea una cuenta de desarrollador en [Spotify Developer](https://developer.spotify.com/).
- Obtén las credenciales y configúralas en el proyecto.
